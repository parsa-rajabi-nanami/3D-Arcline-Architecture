# ARCLINE Architecture

ARCLINE is an editorial architecture, construction, and design-build studio landing page. It is a static, content-led experience with cinematic hero video, a scroll-driven drawing sequence, responsive project imagery, and lightweight interaction details.

Live site: <https://parsa-rajabi-nanami.github.io/3D-Arcline-Architecture/>

## Stack

- React 19 with TanStack Start and TanStack Router
- Vite 8, TypeScript, and Tailwind CSS 4
- GSAP and ScrollTrigger for scroll and pointer motion
- Canvas image sequence for the drawing-to-building transition
- Vitest and ESLint for verification
- Nitro/TanStack prerendering for static HTML output

## Requirements

- Node.js 20.19+ or 22.12+
- npm (the repository lockfile is `package-lock.json`)

The current page does not require environment variables or a backend service.

## Local development

```bash
npm install
npm run dev
```

The development server is available at `http://localhost:5173/`. Production builds use the repository base path `/3D-Arcline-Architecture/` so asset URLs work on GitHub Pages.

## Verification commands

```bash
npm run lint       # ESLint and Prettier rules
npm run typecheck  # TypeScript without emitting files
npm test           # Vitest once
npm run build      # Production client/server build plus static prerender
npm run preview    # Preview the generated build locally
```

`npm run build` writes the deployable static artifact to `.output/public/`. That directory contains the prerendered `index.html`, hashed JavaScript/CSS, and copied public assets. Run `npm run deploy` to create the Pages `404.html` fallback and publish the artifact to the `gh-pages` branch.

## Project structure

```text
src/
  assets/                         Imported, hashed section images
  components/media/               Hero media and fallback behavior
  components/motion/              Shared GSAP reveal behavior
  components/ui/                  Small reusable visual components
  features/landing/               Landing page composition and content
  hooks/                          Browser capability and preference hooks
  routes/                         TanStack Start route modules and document head
  router.tsx                      Router creation and GitHub Pages base path
  styles.css                      Design tokens, global styles, and utilities
public/
  hero/                           Responsive hero video/poster assets
  palace-movie/                   Frames used by the canvas image sequence
  favicon.ico, robots.txt         Public site metadata assets
```

`src/routeTree.gen.ts` is generated by TanStack Router and must not be edited by hand.

## Performance and resilience

- Hero video sources are assigned only after the device breakpoint is known and the hero enters the viewport.
- Reduced-motion, Save-Data, and slow-connection users receive the static hero poster instead of video playback.
- The drawing sequence uses a bounded cache, a capped concurrent image queue, a device-pixel-ratio limit, and viewport-near lazy initialization.
- Pointer effects are limited to fine hover-capable devices and use transform-only updates.
- Images include intrinsic dimensions, lazy loading where appropriate, async decoding, and meaningful alt text.
- Missing or blocked hero video playback falls back to the start poster without breaking the page.

## GitHub Pages deployment

Deployment is handled locally through the `gh-pages` package. Run:

```bash
npm run deploy
```

The `predeploy` script builds and prerenders the site, copies `index.html` to `404.html` for client-side routing, and then `gh-pages` publishes `.output/public` to the `gh-pages` branch.

In the repository settings, set **Pages → Build and deployment → Source** to **Deploy from a branch**, then choose the `gh-pages` branch and `/(root)` folder. The expected URL is:

<https://parsa-rajabi-nanami.github.io/3D-Arcline-Architecture/>

## Content and contact details

The page content, project metadata, navigation labels, and process copy live in `src/features/landing/landing-data.ts` and the landing section components. Update the placeholder studio email and phone number in `CtaSection.tsx` before using the site for a real business.
